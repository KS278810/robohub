# RoboTools

<https://ks278810.github.io/robohub/>

CSV を入れて結果を受け取る小さなツールを、1 画面に並べた入口です。
ツールの画面を選ぶと、その Web 版へ移れます。データはどこにも送信されません。

## このリポジトリについて

**ビルド済みの配布物だけ**を置いています。中身は自動生成なので、直接編集しないでください。

- 履歴は持ちません。更新のたびに単一のコミットを差し替えます
- 公開デモのないツールは、リンクなしで示しています
